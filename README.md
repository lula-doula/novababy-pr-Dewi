# Nova Baby PR

**Nova Baby PR** es un proyecto dedicado a brindar educación perinatal, apoyo en lactancia, preparación para el parto y cuidado prenatal y postnatal, enfocado en la comunidad de Puerto Rico.

---

## Contenido del Proyecto

- Clases y talleres prenatales personalizados
- Servicios de doula y acompañamiento en parto respetado
- Consejos y consultoría en lactancia y manejo de pezones invertidos
- Técnicas de mindfulness y respiración consciente para embarazo y parto
- Recursos y contenido multimedia para madres y familias
